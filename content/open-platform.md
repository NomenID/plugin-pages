开放平台是自带插件，默认启用，入口是 `/open`。它给外部开发者用；站长自己建应用，直接在管理后台的「应用」页就行。

## 开发者流程

1. 用 Nomen 账号登录，打开 `/open`。
2. 填开发者名称，注册成为开发者。
3. 「创建应用」：填名称、说明、主页、回调地址、权限。
4. 创建后 Client ID 和 Client Secret 只显示一次，先存好。
5. 按应用详情页的端点接 OAuth 2.0 授权码流程。

一个开发者最多 10 个应用。密钥可以重置，重置后旧密钥和所有活跃 Token 立即失效。

## 客户端类型

| 类型 | Secret | PKCE | 适合 |
|---|---|---|---|
| 机密客户端 | 有 | 可选 | 有服务端的应用 |
| 公共客户端 | 无 | 强制 | 桌面端、SPA、CLI |

公共客户端没有 Secret 可验，任何知道 Client ID 的人都能发起授权，所以必须靠 PKCE 保护。

## 挂载点

默认 `/open`。路径在 `config/plugins/open-platform.json` 的 `base_path`，也可以在后台「接入点」页改：

```json
{
    "base_path": "/open"
}
```

改完下一次请求生效，旧地址不再响应。

## 关掉插件

从 `config/plugins.php` 的 `enabled` 里删掉 `open-platform`。前台 `/open` 会 404，导航里的「开放平台」也不再出现；管理后台的「应用」页不受影响，仍然可以建应用、改回调、重置密钥。

开发者数据还在 `developers` 表里，重新启用插件后会回来。

## 后台

启用插件后，后台左侧会多一个「开发者」页，列出注册的开发者、他们名下的应用数量和状态，可以停用某个开发者。停用后他不能再登录开发者门户，已经建好的应用仍然按状态工作。
